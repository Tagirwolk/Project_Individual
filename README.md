# Игровой Портал

Веб-приложение для размещения и запуска HTML5-игр с системой авторизации и рейтингов.

## Возможности

- Каталог HTML5-игр с динамической загрузкой
- Поиск и фильтрация по категориям без перезагрузки страницы
- Система регистрации и авторизации пользователей
- Рейтинговая система (оценки от 1 до 5 звёзд)
- Адаптивный дизайн

## Технологический стек

- **Backend:** Python 3.x + Flask
- **База данных:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Безопасность:** Werkzeug (хеширование паролей)
